SwiftMark w3 renders Markdown to HTML in one forward sweep over the source text. An explicit cursor sits at each block boundary and the next construct is chosen by peeking at the upcoming characters: fences, headings, rules, quotes, lists, HTML blocks, reference definitions, tables and paragraphs are each consumed in place, and blockquotes recurse on their stripped sub-source instead of building a document-wide token list first. Because nothing is tokenised twice, long documents stay fast and memory stays flat.

Inline markup is handled by a companion streaming scanner that walks the paragraph text once, resolving escapes, entities, code spans, links, images, emphasis delimiter runs and autolinks as it goes. Emphasis follows the CommonMark delimiter-run rules including the rule of three, tables buffer a single paragraph block just long enough to recognise a delimiter row, and list looseness is decided by a small blank-line lookahead, so the output matches the reference renderer byte for byte without any runtime dependencies.
